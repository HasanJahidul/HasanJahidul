## 📦 Featured Project

### [`zkteco-pull-spring-sdk`](https://github.com/HasanJahidul/zkteco-pull-spring-sdk)

Spring Boot SDK for ZKTeco biometric & access-control devices using **pull-based** sync. Pure Java — no JNI, no native binaries, GPG-signed on Maven Central.

[![Maven Central](https://img.shields.io/maven-central/v/com.hasanjahidul/zkteco-pull-spring-sdk.svg?style=flat-square&logo=apache-maven)](https://central.sonatype.com/artifact/com.hasanjahidul/zkteco-pull-spring-sdk)
[![MvnRepository](https://badges.mvnrepository.com/badge/com.hasanjahidul/zkteco-pull-spring-sdk/badge.svg?label=MvnRepository)](https://mvnrepository.com/artifact/com.hasanjahidul/zkteco-pull-spring-sdk)
[![License](https://img.shields.io/badge/license-MIT-blue.svg?style=flat-square)](https://github.com/HasanJahidul/zkteco-pull-spring-sdk/blob/main/LICENSE)
